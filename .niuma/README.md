协议版本：1

这是知识舱的记忆目录。人可以直接改，Agent 按 skill.md 读写。不要把待办、资料正文、密钥写到这里。

## 这轮就有的文件

- `skill.md`：协议正文。各 Agent 的规则和 skill 由 `bin/init.js` 生成
- `setup.json`：哪些 Agent 已经初始化过。脚本维护，不要手改记忆到这里
- `active.md`：正在做的事。阶段结束后提炼走，不把这里当成已学会的结论
- `rules.md`：偏好。开工只读「现行」
- `facts.md`：用户明确说过的稳定事实。开工只读「现行」
- `gotchas.md`：踩坑。开工只读「现行」
- `knowledge-index.md`：资料索引（正文在仓库的 `library/`）
- `playbooks/`：跑通的流程手册

## 预留名字（先不建空目录）

以后的 CLI / MCP / 日报可以往这些目录写，现在不要预建：

- `journal/`：行为或事件流水，一天一篇，只追加
- `reports/`：日报、周报
- `backups/`：改用户原始文件前的备份（不进 git）

不认识的文件和目录都当扩展，不要删除、不要「清理」。

## 舱内其它层（不在本目录）

- `library/`：知识资料和导入的旧库
- `tasks/`、`projects/`：待办和项目，不分生活/工作
